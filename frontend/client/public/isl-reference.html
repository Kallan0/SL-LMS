How It Works

📸 Capture Pipeline

  • Webcam captures 100×100 grayscale frames
  • MediaPipe extracts 42 hand landmark points
  • Each point has x, y, z coordinates → 126 features
  • PCA reduces 126 → 150 principal components
  • Random Forest classifier predicts the letter

🧠 Model Architecture

  • Algorithm: Random Forest (ensemble of decision trees)
  • Dimensionality reduction: PCA (126 → 150 features)
  • Input: Normalized hand landmark coordinates
  • Output: Predicted letter + confidence score
  • Stored as: isl_classifier.pkl (joblib bundle)

🎯 Landmark Points

  • 4 points per finger (knuckle, middle, tip, side)
  • 4 fingers × 4 points = 16 finger landmarks
  • Thumb: 4 landmarks + wrist reference
  • Palm center + wrist anchor point
  • Hand silhouette bounding box for normalization

📋 Dataset Details

  • isl_landmarks.csv — 7,800 raw landmark samples
  • train_ISL.csv — 10,114 training samples
  • test_ISL.csv — 2,522 test samples
  • Each row: label + 126 float values (f0–f125)
  • Collected via webcam in varying lighting conditions
